## 5. Часовой пояс расписания

В VK расписание работает **по местному времени места показа**, а не по часовому поясу кабинета. Это включает флаг `cross_timezone` («Учитывать временные зоны», [описание объекта FulltimeTargeting](https://ads.vk.ru/doc/api/object/FulltimeTargeting)); мы его установили. Слоты `7…22` — это интервалы 07:00–08:00 … 22:00–23:00, т.е. показы ровно с 07:00 до 23:00 **по времени пользователя**. Часовой пояс кабинета (в профиле VK `timezone = 374`) на это расписание не влияет.

## 11. Ограничения и предупреждения платформы (важно)

1. **Сайт закрыт Basic Auth — блокер запуска.** `https://finindi.ru/` отдаёт `401 Unauthorized`, `WWW-Authenticate: Basic realm="Finindi test"`, nginx/1.31.3. Пока так: модерация VK с высокой вероятностью отклонит объявление, а пользователь по клику увидит запрос пароля. Открытие сайта — решение владельца, агент его не менял.
2. **Пиксель не подтверждён (`working: false`)** → оптимизации на покупку нет, оплата за клики (п. 6). Нужны реальные события `purchase` и цель в кабинете VK.
3. **Модерация объявления — `pending`** (ожидает проверки). При закрытом сайте вероятен отказ; после открытия сайта при отказе потребуется повторная модерация.
4. **ОРД-маркировка не проставлена** (`ord_marker` пуст): VK присвоит токен после проверки/активации, но данные рекламодателя (ИНН, название) в кабинете должны быть заполнены — иначе отказ `ord_data_required`.
5. **Баланс кабинета 4 072,05 ₽** — при 750 ₽/день это ≈5,4 дня. До запуска пополнить.
6. **Дата старта 2026-11-13 уже в прошлом** — после активации показы пойдут сразу.
7. **Цель/пакет нельзя менять после запуска** — все решения по оптимизации принимаются до активации.
8. **UTM живьём не проверены** — сайт недоступен; проверка после открытия.
9. **Прогноз охвата недоступен через API** — снять в кабинете.
10. **Аудитория**: между блоками «И» — охват может быть уже ожидаемого; при необходимости ослабить можно только до запуска и только с согласия владельца.

## 12. Что нужно от владельца до запуска

1. Открыть сайт (снять Basic Auth) — без этого запуск бессмысленен и объявление не пройдёт модерацию.
2. Решить по оптимизации: ждать данных пикселя и переключаться на оплату за покупки (потребует пересоздания группы/пакета) или запускать на кликах как есть.
3. Пополнить баланс кабинета (при 750 ₽/день).
4. Заполнить данные рекламодателя для ОРД в кабинете.
5. Подтвердить дату старта: 13.11.2026 в прошлом → старт по факту активации.
6. Снять прогноз охвата в кабинете и подтвердить, что аудитория достаточная.
7. Дать отдельное разрешение на запуск.
