## 4. Стратегия и цель оптимизации

**Установлено:** «Максимум конверсий» (`WB_MAXIMUM_CONVERSION_RATE`) с оплатой за клики и целью **`purchase` 683156691**. Ответ API: `UpdateResults: [{Id: 716189770, Errors: []}]`. Предупреждений о недоступности цели API не вернул.

Фактическое состояние стратегии (из `campaigns_get`):
```json
{"Search": {"BiddingStrategyType": "SERVING_OFF"},
 "Network": {"BiddingStrategyType": "WB_MAXIMUM_CONVERSION_RATE",
   "WbMaximumConversionRate": {"GoalId": 683156691, "WeeklySpendLimit": 5250000000,
     "BudgetType": "WEEKLY_BUDGET", "BidCeiling": null}}}
```

Что важно: «Максимум конверсий с оплатой за клики» ≠ «Максимум кликов». Переход на «Максимум кликов» **не выполнялся**. Цель `begin_checkout` и другие промежуточные цели для оптимизации **не выбирались**.

Ограничение: у кампании нет истории покупок (показов 0), а интеграция Метрики в click.ru отсутствует — поэтому проверить «достаточно ли конверсий для цели» и увидеть предупреждение интерфейса («серая» цель) невозможно. API принял настройку; **это не доказывает, что цель реально срабатывает**. Проверка — после публикации сайта и реальной оплаты.

## 6. Расписание и возраст — не установлены

**Расписание:** в API/MCP нет настройки временного таргетинга; в интерфейсе Директа для одной кампании можно выбрать **только один часовой пояс** (справка: «Если вы продвигаете услуги в городах с разными часовыми поясами, создайте для каждого часового пояса отдельную кампанию»). Поэтому «07:00–23:00 по местному времени каждого региона» в одной кампании на всю Россию недостижимо. Варианты для решения владельца:
- **A.** 07:00–23:00 МСК (не местное; Камчатка фактически 16:00–08:00 и т.п.);
- **B.** несколько кампаний по часовым поясам (делит бюджет, изменяет структуру);
- **C.** круглосуточно;
- **D.** широкое окно в МСК (компромисс).
Не выбран ни один — как и требовало задание.

**Возраст:** корректировки не применялись (запрещено без согласования). В Директе нет точного «20–45»: только группы 0–17/18–24/25–34/35–44/45–54/55+, и это корректировки, а не жёсткий фильтр (справка допускает показы «исключённым» пользователям). Варианты — в предыдущем отчёте `11_audience_age_schedule_strategy.md`; нужен выбор владельца.
